# Quadratics Unit Progress Checker

Practice page for the Grade 10 (MPM2D) quadratics unit, lessons 4.1 to 4.4.

Six tabs: Equation, Graph, Classify, Find a, Problem, Think. Each question gets two tries, then the answer and worked steps. Progress is saved in the browser on the device being used.

It is a single static file, `index.html`, with no build step and no server.

To change the page, edit `index.html` and push to `main`. Render redeploys on each push.
